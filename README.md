# Clever Ape Studio

The studio's website. The home page is served from `AmeenAhmed/AmeenAhmed.github.io` at
https://ameenahmed.github.io/, and each app's support and privacy pages from `AmeenAhmed/apps` at
https://ameenahmed.github.io/apps/<app>/. Both move to https://cleverapestudio.com/ once its DNS points
at GitHub Pages.

These files are generated from the `site/` folder of a private repo; edits made here are overwritten.

Stack Sans and DM Sans are used under the SIL Open Font License (`fonts/StackSans-OFL.txt`, `fonts/OFL.txt`). The
pictures on the home page are the apps' own screenshots and a screen recording of Vyber.
